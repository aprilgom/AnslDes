## 1.1.0 - 2026-08-17

- blocking/advisory/exception/not-run/deferred budget, viewport·owner attribution과 text/JSON/SARIF effective-rule
  parity를 추가하고, neutral multi-stage report ordering을 회귀 테스트로 고정했다.
- release manifest에 Impeccable/Hallmark/catalog/anti-slop-contract dependency fingerprint를 포함하고 exact
  package·binary·rule-pack pin을 위한 consumer release lock schema와 migration lifecycle을 추가했다.

- `impeccable@3.6.0`의 59개 detector rule과 Hallmark mapping을 canonical 63-rule pack으로 고정하고,
  composable rule-pack registry 및 source/static HTML/browser/visual-contrast Web provider gate를 추가했다.
- Web route/render axis를 consumer policy로 주입하고 full/not-run/execution-error와 exact generated-artifact
  false positive를 결정론적 report 상태로 분리했다.
- Canonical 63개 rule의 Web/React Native/design-document applicability exact mapping과 native supplement를
  추가하고, React Native source의 justify/reveal/raw-animation 및 document visitor metadata를 검증한다.
- Exact exception/ignore와 90일 review contract, CI/report anti-bypass verifier 및 semver 기반 rule-pack
  addition/removal/replacement governance를 추가했다.
- React Native source와 iOS/Android runtime evidence를 분리하고 accessibility, target, environment, performance,
  appearance, adaptivity와 exact capture matrix를 검증하는 15개 native conformance 규칙을 추가했다.
- Web/native route failure, reveal fallback visibility와 exact print/export justify permission을 검증하는 3개
  runtime/general-quality 규칙 및 detector-process failure 경계를 추가했다.
- Consumer asset registry의 owner·source·consumer·fingerprint와 Web/native load/accessibility evidence를 검증하는
  2개 imagery 규칙을 추가했다.
- Versioned locale phrase/content provenance registry와 한국어 적용 경계, non-blocking English em-dash advisory를
  포함하는 6개 copy 규칙을 추가했다.
- Consumer motion registry의 owner·purpose·resolved duration/easing과 platform Reduce Motion fallback을 검증하는
  6개 motion 규칙과 source/runtime/design-document evidence를 추가했다.
- Browser, native runtime/source와 design-document 공용 layout evidence, semantic spacing 관계 및 14개
  layout/space 규칙을 추가했다.
- Consumer definition의 contrast registry·theme mapping·context-scoped palette 승인을 사용하는 theme별 color
  evidence와 9개 color/contrast 규칙을 추가했다.
- Profile-scoped typography evidence와 14개 hierarchy/legibility 규칙, 100%·235% font-scale fixture 및
  Hallmark overused-font provenance를 추가했다.
- Web, native와 design-document provider 공용 visual-detail evidence와 side-tab, rounded accent,
  thin-border/wide-shadow, repeating stripe, grid 및 ListRow accessory wrapper 규칙을 추가했다.
- Canonical definition에서 versioned `DESIGN.md`/design sidecar를 생성하고 stale SHA를 차단하는
  design-system awareness 계약과 font, color, radius, font-size rule mapping을 추가했다.
- `operate`, `read`, `browse`, `create` consumer profile과 strict conformance evidence 계약을 추가하고 control
  contract, affordance, motion, prominence, action consistency와 interactive state를 결정론적으로 검사한다.
- 공통 `RuleSpec` registry, versioned rule pack fingerprint와 exact governed activation override를 추가했다.
- JSON Schema 2020-12 기반 `deslint` report v1 계약을 추가하고 Web, native, design-document와 runtime
  evidence kind를 분리했다.
- finding status와 rule activation을 분리하고 canonical/source rule provenance, exact false-positive와
  optional visual judgment 경계를 report에 추가했다.
- blocking finding은 exit code 2, 실행 실패는 exit code 1로 구분하고 optional judgment가 deterministic
  verdict와 fingerprint를 변경하지 못하게 했다.

## 1.0.0 - 2026-08-16

- Definition과 compiled bundle을 v2로 올리고 v1 호환 경로를 제거했다.
- Color, spacing, radius, size에 `primitive → semantic → component` 단방향 참조를 강제한다.
- Component recipe가 layered foundation의 primitive·semantic·asset token을 직접 소비하면 schema/compiler/`deslint` gate가 실패한다.
- Raw spacing·radius·size 값은 primitive에만 선언하도록 generic fixture와 회귀 테스트를 이관했다.
